# Student_Recorder
The Student Record Manager is a lightweight web application that helps a user maintain a collection of basic
student records. Through a simple interface, the user can enter a roll number, student name, Gmail address, and
age. The application validates the entries, prevents duplicate roll numbers, and saves accepted records in the
browser's local storage.
The interface is built with a modern visual design: a dark gradient background, animated particles and glowing
shapes, glass-style cards, responsive layouts, input feedback, and small success animations. The design aims to
make a basic record-management task more approachable and visually engaging
